## 推荐方案 A：保留绕锚点操作，改成镜头局部运动碰撞

这是待实现、待验证的设计，不能声称已通过测试。

### 行为约定

保留初始高位俯视、WASD 视角相对平移、空格/Ctrl 升降、中键绕锚点旋转、现有范围定义及退出恢复。障碍只约束镜头自身扫过的空间；遇墙截停或贴墙滑动，不沿锚点长连线弹回。空旷场景的镜头轨迹应与修复前一致。

不要只禁用避障、减少射线数量、降低移动速度或加入距离平滑：它们不能同时满足局部连续运动和不穿墙。不要悄悄把绕锚点旋转改成原地自由转头；那是另一项交互决策。

### 状态与每帧求解

1. 明确区分逻辑锚点 A、朝向 R、实际光学镜头中心 C。由原版坐标变换核对 `C = A + B(R)`，B 包含固定后退向量与代理实体眼高偏移；不要用玩家脚底位置直接代替光学中心。
2. 保存上一帧已接受的 A、R、C。从现有输入计算候选 A、R，仍用 `FreecamRange.clampCamera` 约束逻辑锚点；不得本轮悄悄改成约束镜头中心，二者范围不同。
3. 在上一 C 到候选 C 的路径上约束一个小型镜头包围体，复用 Minecraft 方块碰撞形状/包围盒及轴向 offset 求解能力。平移采用 swept broadphase 与窄相求解，不只测终点，避免穿薄墙。只查询已加载区块，未加载边界阻挡，不主动加载世界。
4. 旋转按绕锚点的圆弧路径检测，单条首尾弦不足。按弧长/角度与镜头体尺寸推导步长，有明确单帧步数上限；达到上限保留最后安全状态，不跳到未检查终点。遇阻停止未接受的旋转部分，首版无需复杂旋转滑动。
5. 平移被阻挡时可复用原版轴向滑动；只有在实际碰撞安全且锚点范围仍有效时接受结果。把实际接受位置回写为新的逻辑状态，使 `C = A + B(R)` 继续成立。禁止积累一个穿到墙后的目标，再在离墙时追赶或弹出。旋转保持锚点不动并只接受安全角度部分。
6. 同帧移动和旋转使用固定顺序并测试组合输入；可先旋转再平移。位置与旋转均只从已接受状态继续，避免两个独立修正互相拉扯。
7. 镜头体大小根据近裁剪面、FOV 和宽高比核对。可选保守球体外接 AABB 以避免转头时盒体突然变形，但不能未经测量写死一个半径并宣称解决近裁剪穿墙；明确保守间隙与狭窄空间通行的取舍。

### 渲染接入

自由模式应渲染求解后的 C，不再执行原版锚点长连线回缩。优先寻找现有最窄渲染接入点；如需 `FreecamTransformer` 钩子，仅对有效自由会话替换相机变换/距离逻辑，普通第三人称完全走原版。不能全局开启 debugCam 或切第一人称来省略碰撞，二者还影响手部、玩家模型和其他渲染。

可保留逻辑代理实体在 A，通过精确变换钩子使用已解算的 C；不要在未核对光标反投影、渲染原点和实体剔除坐标之前把代理实体直接搬到 C。核心补丁需要验证反混淆/混淆名称与 lwjgl3ify 下真实字节码命中次数，补丁失配应可观测且安全退出模式，不静默留下穿墙相机。

此渲染接入形式尚未做逐指令可行性验证，是实施前必须补齐的技术缺口。先核对原版完整变换，再决定最小补丁，而不是直接采用本段猜测写 ASM。

### 初始进入、地面及异常情况

- 首次进入没有上一镜头位置，可只在初始化时从安全起点沿初始后退路径选择安全镜头位置；后续运动不得继续对长连线避障。遮挡导致初始镜头近于固定后退位置时，必须同步一个一致且范围内的锚点/镜头状态；无法满足则保持原视角并记录原因，不能首帧安全、第二帧跳回。
- 统一局部碰撞覆盖地面、墙面、天花板后，移除或整合现有 `getDropFloor`，避免它继续按锚点列扫描并与镜头碰撞互相修正。
- 保留既有防潜入液体/地底体验：液体原生碰撞盒常为空，不能因换用实体碰撞盒就丢掉液面下降限制。实现时明确仅下降跨液面阻挡还是全方向阻挡，保持现有语义优先。
- 动态方块把镜头包住、玩家移动导致范围收缩、FOV/窗口变化使镜头体不再适配时，采用有界局部恢复；无合法位置则安全退出并恢复原视角，禁止扫描到树顶/屋顶强行传送。
- 菜单、失焦、死亡、换世界、断线沿用既有会话清理；玩家位置与服务端交互范围保持原逻辑。

### 影响范围与最小实现结构

预计触及旧版 FreecamClient、必要的渲染 Transformer 钩子以及一个具体相机碰撞求解类/现有运动类中的小模块。不要建立跨版本接口、策略系统或额外依赖。FreecamSelection 原则上继续读取实际矩阵，但必须验证坐标还原；交互协议和服务端距离校验无需随相机重构放宽。

## 备选方案 B

把代理实体改成实际镜头位置，使用原地旋转，保留初始俯视构图并做局部碰撞。这可以减少绕锚点圆弧求解与回写复杂度，但改变现有中键手感和范围坐标语义。只有用户明确接受该体验变更才采用。单纯增加距离平滑只能缓解弹出，不能作为解决本问题的备选完成态。

1. 重建最小复现并保留失败断言。使用原版算法与真实世界射线，单个完整方块 `(0,65,-2)`；锚点由 `(-0.12,65.5,0.5)` 移至 `(-0.10,65.5,0.5)`，yaw/pitch=0，距离=13.856406F。中心线与镜头自己的短位移线应为空，原算法发生大回缩。旋转案例锚点 `(-0.15,65.5,0.5)`，yaw 从 0 到 4°；垂直案例 x=0.5,z=0.5，y 从 66.11 到 66.09。坐标是诊断模型光学锚点，不直接等同游戏代理实体 posY。
2. 核对旧版完整 GL 变换与全部调用点；先证明空旷轨迹等价，再引入碰撞求解。设计测试 seam 为“世界碰撞查询 + 上一接受镜头状态 + 输入 → 新接受镜头状态”。

4. 在渲染补丁 seam 检查仅自由模式接管、真实字节码恰好命中预期入口，普通模式回退正常。复用无框架 Java 检查与已有脚本，不新增测试依赖。
