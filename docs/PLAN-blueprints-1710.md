## 2. 已确认产品契约

### 2.1 法杖和核心

- 普通、高级、创造法杖各有 4 个升级槽；手持法杖蹲下右键（对空气及方块）打开容器 GUI，可安装和取出多种升级核心。本次仅实现蓝图核心，同种核心不叠加。
- 蓝图核心为物品，新增贴图、中英文名称、说明和合成配方：四角纸、四边红石、中心钻石，产出 1 个。配方不依赖 GT/AE2。
- 当前实际生效法杖安装核心才提供蓝图能力，不采用“背包任意一把有核心”的判断。自动接续后重新校验，核心失效退出当前蓝图操作，已保存蓝图及任务保留。
- 打开升级 GUI 时锁定被编辑法杖的物品身份和槽位，校验移动、替换、Shift 点击、死亡和关闭，避免核心复制或丢失；旧法杖缺少升级数据视为空槽。

### 2.2 选区与个人蓝图

- 自由视角 HUD 蓝图按钮进入选择状态；左键依次选实际方块 A、B，包含两端，定义轴对齐长方体，允许退回重选及取消。选点不触发挖掘或原版使用。
- 整个选区须满足当前法杖范围、世界高度和服务端有效区块条件。保存名称不能为空；同名不得静默覆盖。列表支持选择和删除。
- 保存相对于 A 的坐标（可为负数）、尺寸、方块类型/变种、朝向、配置及附属部件。蓝图属于服务器存档中的玩家 UUID，不作为背包物品，不向协作者公开个人蓝图库。
- 不复制机器/箱子内部物品、流体、能量、运行进度。GT 覆盖板和 AE2 石英纤维、线缆锚等为需记录、耗材重建的实际部件，不作为应剔除的普通库存。
- 记录 GT 机器配置、覆盖板及参数、管道/线缆各面的连接断通；记录 AE2 各方向部件、配置、线缆及附属结构。
- 无法可靠记录或复建的特殊方块必须明确列出并阻止保存，不静默省略或以普通方块降级。不能声称通用 NBT 拷贝已满足任意 Mod 的完整兼容。

### 2.3 预览和任务

- 列表选蓝图后回到世界，光标移动显示虚影；以原 A 为投放参考，保持原方向，再次点击固定为待建造任务。提供取消未固定预览的出口。
- 虚影为客户端渲染，无实体碰撞，不影响穿行；不是把假方块写进真实世界。表现应能辨识所需方块和附属部件，不以单一选区线框代替整张蓝图。
- 任务保存独立蓝图快照或稳定不可变引用，删除个人蓝图不破坏已创建任务。任务绑定主人 UUID、维度、投放原点和唯一 ID。
- 任务列表在自由视角 GUI 内可查看。任务正常退出、重进和服务器重启后保留；完成后显示完成状态，隐藏虚影。
- 未完成虚影选中后展示权限允许的控件。默认在自由视角外也显示；该选项只影响模式外显示，不覆盖下面的他人权限。

### 2.4 多人权限（最终确认，覆盖此前“仅主人建造”建议）

| 他人权限 | 其他玩家列表/虚影 | 其他玩家施工 |
| --- | --- | --- |
| 不可见 | 隐藏 | 禁止 |
| 可见但不可建造（默认） | 可见 | 禁止 |
| 可建造 | 可见 | 允许符合条件者 |

- 主人始终能查看管理自己的任务；只有主人能取消、修改三档权限、切换模式外虚影可见性。
- 协作者必须处于自由视角，当前生效法杖装有蓝图核心，且目标满足协作者自身操作范围与世界权限。
- 协作者消耗自己的主背包材料和法杖耐久；不能操作主人的库存。开放施工不等于共享蓝图原始文件。
- 权限服务端强制校验，不能只隐藏按钮。修改为不可见时清理其他客户端任务、虚影及缓存；权限收回阻止后续施工步骤，不撤回已建方块。
- 只有同维度、可见距离内的获准玩家接收必要虚影数据。未装核心的玩家仍可在允许的情况下观看，不因此获得施工资格。

### 2.5 建造与取消

- 点击建造启动服务端有预算的分批操作，尽量填充可完成部分；缺料显示清单，补料后再次点击继续。不要求单帧放完整个建筑。
- 材料包含方块实体对应物品及 GT/AE2 实际部件。成功放置方块或安装部件各扣 1 点法杖耐久，失败不扣；配置恢复不能额外制造物品。
- 创造法杖免耐久；生存玩家持创造法杖仍耗材料，创造模式玩家免材料。
- 已有结构及配置匹配时跳过，不重复扣料。不同方块或配置冲突时提示，不自动拆除、覆盖、清空容器；蓝图空气不挖空地形。
- 方块、配置、部件全部满足后才完成。允许在本任务已放置的基体上补充尚缺部件；不得把任意陌生同类机器当成可覆盖配置的自有基体。
- 取消删除待建状态及虚影，已填充方块留在世界，不自动回收。
- 多人同时施工同一位置仅结算一次；重复点击不重复排队，不重复扣料。超范围、未加载、断线、核心/耐久失效和权限变化时停止后续步骤并可恢复。

## 4. 建议实现结构与顺序

以下是工程建议，不是已存在类名；实施者可调整内部结构，但不能改变第2节用户行为。

### 阶段 A：固定版本兼容调查与数据模型

1. 核对现有分支、依赖、源码/反编译内容，逐类查明 GT/AE2 的写入读取及部件生命周期。研究断通状态更新后是否被邻居更新覆盖。
2. 建立 blueprint 包：元数据、相对坐标条目、物料需求、适配器版本、任务权限和施工状态。区分静态配置、实物附件、资源库存、运行态、世界身份/坐标。
3. 为原版、GT、AE2 建立适配器 capture/materials/validate/place/restore/matches/renderData。先列支持能力及不支持诊断，再接 GUI；不得用删几个常见 NBT 键的方式宣称清空所有 Mod 内部资源。
4. 查明 AE 升级卡、编码样板、GT 程序电路等边界：实体物品不可免费复制，纯配置不应被误删。现有契约能明确归类的按契约实现；无法归类且影响玩法时提交具体增量问题，禁止悄悄丢弃需求。

### 阶段 B：持久化和网络

- 建议存于服务器存档内 `freecam_interaction/blueprints/<uuid>/` 和 `freecam_interaction/tasks/`；使用 UUID/内部 ID 作为文件名，显示名称不拼路径。
- 使用有版本的分段二进制格式、方块/配置调色板与压缩；NBT 可以用于 Mod 单条适配接口，但完整蓝图容器不得为整块 NBT。每段设置长度和解压上限、校验和、条目计数，采用临时文件完成后原子替换，坏文件报错隔离而非覆盖原始数据。
- 明确限制：选区体积、非空气条目、单条配置字节、总压缩/解压字节、并行请求、每玩家任务数与渲染预算。数值尚未实测，实施者依据固定版本协议/内存和代表性蓝图测量制定、写入配置与说明；超限提前说明，不截断数据。
- 服务器从真实世界采集，客户端只发 A/B、名称、任务 ID、落点等意图；不得信任客户端提供任意方块/NBT/他人 UUID。
- 世界读取、放置、库存操作在服务端 tick 主线程执行；文件工作若移至后台，仅传不可变快照。长采集需检查相关区域在处理期间是否变化，变化重试或报告，不保存混杂快照。
- 分片消息含 requestId/transferId、版本、片序号/总数和限额；防重复、乱序、超时、过期响应。先发列表元数据，再按需发预览，不广播整个私人蓝图库。
- 任务权限/进度变化发修订号和增量；进入维度、进入可见范围、重连和重启重新同步。不可见任务不给其他玩家原始数据。服务端校验所有管理操作主人身份。

### 阶段 C：升级容器与客户端交互

- 新增 UpgradeContainer、服务端 GUI handler、客户端升级页；容器防非法物品/重复核心/编辑中移动法杖，关闭正常归还暂存物。
- 新增明确客户端状态：普通、选A、选B、命名、列表、投放预览、任务选中；Screen 焦点与原自由视角控制协作。菜单/失焦/中键旋转后继续沿用松键解锁，关闭 GUI 不误挖世界。
- 蓝图列表/任务列表提供空态、分页、处理中/失败提示和返回，长名称不溢出。主人控件包含建造、取消、三档权限、模式外显示开关；协作者只有获准建造入口。
- 虚影渲染采用只读预览世界/适配器上下文，不把预览 TileEntity 注册进真实 tick 或 AE 网络。按距离和区块裁剪、缓存网格、限制每帧创建开销，任务权限失效时销毁缓存。
- 虚影颜色区分待建、缺料/冲突等必要状态；正确显示机器/管线/部件形状。调用原 Mod 渲染前核实可否在预览上下文运行，不允许造成真实世界副作用。

### 阶段 D：服务端施工和资源结算

- 每个任务由服务端串行调度，工作单元是一个可验证的方块/部件操作；每步重新检查权限、模式、核心、材料、耐久、落点、维度和事件权限。
- 先生成依赖顺序（基体、附属部件、朝向配置、连接状态与通知），处理多方块、附着物与稳定连接；不以空气需求破坏地形。匹配判定忽略能源/库存/运行进度等被排除数据。
- 以服务端现有真实结构复核重复/恢复，而非仅相信进度计数。预留材料后实施，成功提交扣料，失败释放预留并恢复本操作；兼容事件取消，不以直接 setBlock 绕开权限。
- 块和物品不是总能一一对应，GT meta tile ID 和 AE 部件需适配器返回确切物料；不免费制造容器内容或附件。区分任务已放置待配部件与外部冲突结构。
- 记录任务状态与操作进度，使正常保存/重启可恢复；考虑进程中断在“世界写入/背包扣料/任务保存”间的恢复，设计最小日志或核对机制，避免盲目重复扣款。不能仅凭文件原子替换声称多系统事务成立。
- 有材料就推进，缺料/阻塞保留任务并显示原因；取消、权限变化、玩家断线、死亡或换维度令后续操作停止，清理队列/传输，不自动继续离线施工。
- 完成条件是全部预期结构/配置/部件复核通过。完成后释放虚影数据，保留完成状态；取消的现有方块不回滚。

### 阶段 E：贴图、验证、文档

- 蓝图核心建议沿用32×32透明像素物品材质。生成时使用 imagegen 技能及规定工具，保留提示词、原始图和实际产物，目视核验；不要仅生成方案图而未接入资源。
- 日志记录请求/任务ID、阶段、位置、适配器、失败原因、材料和进度变化，复用现有 logs 命名约定（Windows使用 HH-mm-ss），不输出完整库存或蓝图负载。
- 新增聚焦蓝图检查与可复用 PowerShell 入口；现有 smoke 较宽时拆出最小针对性验证，不反复全量运行。
- 更新两工作树 AGENTS.md/MEMORY.md，精确到分钟且倒序；1.21.1 保持待实现。记录真实完成和未验收项，不把计划或构建通过写成玩法验收。
